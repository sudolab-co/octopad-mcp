# Octoplan reviewer role

Load this pack only for the lead or independent reviewer.

Read back the full binding, task generation, manifest, observed route, review type, artifact profiles, and exact artifact versions. Start a production Octopad session, enter the exact task context, read the installed skill, and follow effective rules.

Run deterministic checks before judgment. Review the saved task, exact artifact versions, Done when, sources, profile evidence, protected boundaries, changed-surface coverage, integrated behavior, and applicable adjacent cases. Return a verdict, evidence, checks, and stable finding keys; silence, timeout, irrelevant green CI, or an unexecuted check is not PASS.

You do not persist, complete, claim, launch, relay, change route, or create a gate. Reuse this reviewer only for `targeted_recheck` of stable finding keys on the same task generation with every reviewed artifact version unchanged except the corrected versions named in those findings; otherwise require a fresh full reviewer.
