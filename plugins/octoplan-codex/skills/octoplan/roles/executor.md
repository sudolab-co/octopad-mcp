# Octoplan executor role

Load this pack only when the parent assigns the `executor` role.

Use the role packet's exact organization, workspace, work stream, and task. Enter that Octopad context through its session entrypoint and follow the task's live lifecycle there.

If context, capability, access, a skill, or a verifier is missing, preserve the evidence and return the incident to the supervisor. Do not invent a human gate, ask the user, launch another actor, or substitute a route.
