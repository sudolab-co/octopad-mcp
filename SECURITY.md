# Security

Do not post a suspected security flaw in a public GitHub issue.

Email [support@octopad.ai](mailto:support@octopad.ai) with the subject `Security report`. Include:

- what you found;
- the affected page, command or client;
- clear steps to reproduce it;
- the effect you observed;
- any logs or screenshots with secrets and personal data removed.

For general product or account help, use the same email without the `Security report` subject.

Read the [Octopad Privacy Policy](https://www.octopad.ai/privacy) for information about data handling.
